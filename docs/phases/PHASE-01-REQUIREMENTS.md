# Phase 1: Requirements Analysis

## Objective
Establish the functional and non-functional specifications, user personas, operational scope, and academic learning requirements for the Jaya Akademisi LMS platform at Universitas Pembangunan Jaya.

## Activities Performed
1. Formalized stakeholder roles: Administrator, Lecturer, Student.
2. Drafted functional requirements covering authentication, course management, syllabus structure, enrollment, interactive classroom, assignments, grading, and progress metrics.
3. Specified non-functional requirements prioritizing zero-cost local operation, low-latency SQLite transactions, modern UI ergonomics, and clear separation of concerns.

## Features Developed & Specified
- Role-based access control (RBAC).
- Coursera-inspired Course Catalog and detailed syllabus preview.
- Sequential Module and Lesson classroom view with multimedia embedding.
- Real-time lesson completion tracking and percentage calculation.
- Assignment submission and grading lifecycle.
- Administrator overview and user management.
